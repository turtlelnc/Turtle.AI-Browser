## 📥 安装方式

### 方式一：安装器（推荐）

把下面两个放在**同一个文件夹**里，双击 `TiBrowserSetup.exe`：

```
TiBrowser-1.0.1-rc2-win-x64/
├── TiBrowserSetup.exe    # 安装程序
└── dist/                 # 程序本体
```

- 安装到 `%LOCALAPPDATA%\Programs\TiBrowser`，**用户级安装，不需要管理员权限**
- 自动创建开始菜单与桌面快捷方式，并注册"应用和功能"里的卸载项
- 卸载时会询问式地保留浏览数据（书签/历史/设置），不擅自删除

命令行选项：`--silent`（静默安装）、`--dir=<路径>`（指定目录）、
`--uninstall --silent`（静默卸载）。

### 方式二：免安装便携版

直接把 `dist/` 整个目录复制到任意位置，运行其中的 `TiBrowser.exe`
（或双击 `启动 TiBrowser.cmd`）。

### 系统要求

Windows 10 1809 及以上（64 位）。无需安装 .NET、VC 运行库或任何运行时 —— 
程序为静态 CRT 链接，只依赖随包的 CEF 运行时文件。

## 🆕 rc2 相对 rc1 的变化

**新增**
1. **扩展加载**：支持 `.crx`（CRX2 / CRX3）与已解压目录，经原生文件对话框选择；
   内置 ZIP 解包器（含目录穿越防护），直接以 zip 分发的扩展也能加载。
2. **无痕模式 2.0 的指纹注入真正生效**：按指纹画像（UA / 平台 / 时区 / 语言 /
   屏幕 / 并发数 / DNT + Canvas 与 WebGL 噪声）在页面加载时注入。
3. **键盘快捷键**：Ctrl+T / W、Ctrl+Shift+T（恢复关闭的标签页）、Ctrl+Tab、
   Ctrl+1..9、Ctrl+L / F / R / D / H / J、Ctrl+± / 0、Alt+←→、F5、F11、F12，
   焦点在网页输入框内同样生效。
4. **原生安装器**（自研，零外部依赖）。

**修复**
- `--incognito` 此前没传给窗口创建，"无痕窗口"实际是普通窗口。
- 新建标签页会停在 `about:blank`（一片空白）。
- 标签页 URL 一直为空，连带影响关闭后恢复、书签、网页应用。
- 设置改了不起作用：状态推送里的设置快照写死了默认值，会覆盖真实设置
  （皮肤 / 主题 / 书签栏开关都受影响）。
- 首屏引导数据同样写死默认值，导致首帧按默认主题绘制。
- 每个标签页会被导航两次（回调触发两次），第二次会覆盖首次导航。

## ⚠️ 已知问题（如实列出）

1. **开第二个标签页后约 9 秒崩溃**（`libcef.dll`，0xc0000005）。
   当前唯一影响日常使用的稳定性缺陷。单标签页可稳定运行。
   最小复现：`TiBrowser.exe --url=https://example.com --open=https://example.com`。
2. **本机需以"单进程兼容模式"运行**：Chromium 的网络服务子进程在此环境下启动即崩，
   会导致任何网页都打不开。启动日志里会如实标注当前进程模型；
   在正常环境可用 `--multi-process` 恢复标准的多进程隔离。
3. **安装包未做代码签名**，Windows SmartScreen 会提示"未知发布者"。
4. 三档安全浏览中依赖云端威胁库的能力需要自备服务商 API Key，界面会明确标注。
5. Microsoft / Google 账户云同步需要自备 OAuth client id；
   本地文件夹同步可直接使用。
6. 扩展目前完成了解包与登记，**Chromium 侧的实际加载尚未接入**。
7. `%LOCALAPPDATA%\TiBrowser` 在本机用于存放浏览数据
   （不使用 `%APPDATA%`：该目录被 OneDrive 同步会导致 Chromium 缓存占用冲突）。
