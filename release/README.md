## 🆕 rc1 新增（十五项）

1. **完全 Chromium 内核** —— 主程序直接链接 CEF，真 Chromium 150。
2. **Edge / Chrome 全量能力 + UI 大更新** —— 日常浏览能力对齐，外壳整体翻新。
3. **Microsoft / Google 账户登录与同步** —— 支持登录，并提供同步状态与手动同步。
4. **无痕模式 2.0 / 指纹可改** —— 无痕++，独立上下文 + 指纹画像可调可随机化。
5. **安全浏览三档** —— 增强型 / 标准 / 不防护，档位含义与云端行为在界面上写明。
6. **不安全安装包可保留 + turtlelnc 内容自动放行** —— 下载不再被直接删除，防误杀。
7. **生成网页应用** —— 任意网站一键安装为独立网页应用。
8. **TiBrowser / Edge / Chrome 皮肤切换** —— 一套外壳三套皮肤。
9. **AI 连接支持 API / MCP / OAuth(SDK)** —— 三种接入方式并存。
10. **整合各浏览器优点** —— Chrome 的兼容、Edge 的效率、国内浏览器的实用细节。
11. **一个浏览器解决所有事** —— 浏览、AI、防护、办公开发、网页应用、账户同步一体。
12. **本地办公模式与本地开发模式** —— WorkBuddy 能力 / Tare + codex 能力。
13. **能效四档** —— 标准 / 快速 / 低占用 / 即开即用。
14. **Apple 风格 UI 优化** —— 视觉与动效按 Apple 设计语言重做。
15. **本地控制接口** —— 面向用户自有 AI 工具 / CLI / harness 的本地自动化 API。

## 📥 安装

### Windows 10/11

| 架构 | 安装包 | 适用 |
|---|---|---|
| **x64**（64 位） | `TIbrowser-1.0.0-rc1-x64-setup.exe` | 绝大多数电脑（推荐） |
| **x86**（32 位） | `TIbrowser-1.0.0-rc1-ia32-setup.exe` | 老旧 32 位电脑 |
| **ARM64** | `TIbrowser-1.0.0-rc1-arm64-setup.exe` | 骁龙等 ARM 笔记本 |

安装步骤：

1. 下载与你的系统架构匹配的安装包（不确定就选 **x64**）；
2. 双击运行，按向导选择安装目录（支持自定义路径、非静默安装）；
3. 从桌面快捷方式或开始菜单启动 **TIbrowser**。

### SmartScreen 提示

安装包**未做代码签名**。首次运行 Windows SmartScreen 会提示「Windows 已保护你的电脑 / 未知发布者」，
点击 **「更多信息」→「仍要运行」** 即可继续。若你的环境禁止运行未签名程序，请先在测试机上验证。

### Linux / macOS

Linux（AppImage）与 macOS（dmg）产物**需在对应系统或 CI 上构建**，
Windows 上无法交叉打包。构建配置见仓库根目录的 `electron-builder.yml`。

## ⚠️ 已知限制（rc 通道，务必阅读）

- **可能崩溃**：本版本为候选发布，稳定性尚未收敛，请勿用于重要场合，并注意备份数据。
- **本地黑名单为样例**：未接入真实威胁情报源，拦截能力有限。
- **增强型防护部分能力不可用**：依赖 Google 云端的能力在本地不可用，**界面会明确标注**。
- **账户同步不完整**：需用户自备 OAuth client id，云端同步能力尚不完整。
- **扩展兼容性受限**：受 Chromium 嵌入方案限制，部分扩展无法完整运行。
- **无代码签名**：SmartScreen 会提示未知发布者（见上）。
- **无基准数据**：本版本未发布任何性能或兼容性跑分，请以实际体验为准。

## 🔄 升级说明

> **重要：v0.1.0 / 1.0.0-beta 与 v1.0.0-rc1 不互通。**

- rc1 **更换了内核**（Electron → 原生 C++ + CEF），同时**更换了数据目录**，
  旧版本的配置、登录态、扩展、AI 设置**不会自动迁移**。
- 两个版本的安装目录与用户数据目录相互独立，可以**并存安装**，便于对照排查。
- 如果确实需要带走旧数据：请**先用旧版本导出 `.tbuser` 文件**
  （旧版：设置 → 配置文件同步 → 导出），再在 rc1 中导入。
  但请注意 **rc1 的数据格式已经变化**，导入**仅迁移书签 / 历史 / 设置**这三类，
  其余内容（扩展、账户登录态、会话、下载记录等）**不会迁移**，需要重新配置。
- 反过来，rc1 导出的 `.tbuser` **不能被旧版本导入**。

建议：首次升级前先备份旧版本的用户数据目录，确认 rc1 可用后再清理。
