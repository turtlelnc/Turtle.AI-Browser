## 📥 安装方式

### 方式一：安装器（推荐）

把下面两个放在**同一个文件夹**里，双击 `TiBrowserSetup.exe`：

```
TiBrowser-1.0.1-rc2-win-x64/
├── TiBrowserSetup.exe    # 安装程序
└── dist/                 # 程序本体
```

- 安装到 `%LOCALAPPDATA%\Programs\TiBrowser`，**用户级安装，不需要管理员权限**
- 自动创建开始菜单与桌面快捷方式，并注册"应用和功能"里的卸载项
- 卸载时会询问式地保留浏览数据（书签/历史/设置），不擅自删除

命令行选项：`--silent`（静默安装）、`--dir=<路径>`（指定目录）、
`--uninstall --silent`（静默卸载）。

### 方式二：免安装便携版

直接把 `dist/` 整个目录复制到任意位置，运行其中的 `TiBrowser.exe`
（或双击 `启动 TiBrowser.cmd`）。

### 系统要求

Windows 10 1809 及以上（64 位）。无需安装 .NET、VC 运行库或任何运行时 —— 
程序为静态 CRT 链接，只依赖随包的 CEF 运行时文件。

## 🆕 rc2 相对 rc1 的变化

**新增**
1. **网页右键菜单**（原生 Views 菜单，22 项，按上下文动态启用/禁用）：返回 / 前进 / 重新加载 /
   停止加载、在新标签页中打开链接与图片、复制链接地址与图片地址、链接另存为、图片另存为、
   撤销 / 重做 / 剪切 / 复制 / 粘贴 / 删除 / 全选、搜索选中内容、放大 / 缩小 / 重置为 100%、
   打印为 PDF、查看页面源代码、检查元素。此前网页区域右键**不会弹出任何菜单**。
2. **下载管线**：下载落到数据目录的 `Downloads`，进度与结果写入下载列表。
3. **下载安全判定真正接上了**：不安全安装包（.exe/.msi/...）**只警告不拦截**、文件照常保留、
   记录标为可疑并写明原因；turtlelnc 发布物直接放行。
4. **无痕模式 2.0 的指纹改写增加回读验证**：页面加载完成后在页面里回读实际取值并与画像逐项比对
   （验收结果：一致 6 项、不一致 0 项）。
5. **扩展管理**：支持 `.crx`（CRX2 / CRX3）与已解压目录，经原生文件对话框选择；
   内置 ZIP 解包器（含目录穿越防护），直接以 zip 分发的扩展也能导入。
   **注意：只能登记，不能运行**（见"已知问题"第 2 条）。
6. **键盘快捷键**：Ctrl+T / W、Ctrl+Shift+T（恢复关闭的标签页）、Ctrl+Tab、
   Ctrl+1..9、Ctrl+L / F / R / D / H / J、Ctrl+± / 0、Alt+←→、F5、F11、F12，
   焦点在网页输入框内同样生效。
7. **原生安装器**（自研，零外部依赖）。

**修复**
- **开第二个标签页后约 9 秒必定崩溃**（`libcef.dll`，0xc0000005）：根因是在窗口创建过程中
  摘除已挂载的网页视图。改为"切标签只切可见性"，多标签连续 60 秒稳定。
- **关闭窗口后进程不退出**（单进程模式下 CEF 不会自动结束消息循环）。
- **`--user-data-dir` 与 `--multi-process` 静默失效**：在 `CefInitialize` 之前取全局命令行
  拿到的是空对象，分支根本没进入；现在两个开关都实测生效。
- `--incognito` 此前没传给窗口创建，"无痕窗口"实际是普通窗口。
- 新建标签页会停在 `about:blank`（一片空白）。
- 标签页 URL 一直为空，连带影响关闭后恢复、书签、网页应用。
- 设置改了不起作用：状态推送里的设置快照写死了默认值，会覆盖真实设置
  （皮肤 / 主题 / 书签栏开关都受影响）。
- 首屏引导数据同样写死默认值，导致首帧按默认主题绘制。
- 每个标签页会被导航两次（回调触发两次），第二次会覆盖首次导航。
- 版本号全线对齐（Windows 文件属性、边车自报版本、发行说明、UI 构建号），
  并由 `npm run check` 加了防回归检查：以前升级版本号时这几处会静默留在旧值。
- `service/package-lock.json` 里遗留的 `MIT` 许可证声明已改为 `GPL-3.0-only`。

## ⚠️ 已知问题（如实列出）

1. **本机需以"单进程兼容模式"运行**：Chromium 的网络服务子进程在此环境下启动即崩，
   会导致任何网页都打不开。启动日志里会如实标注当前进程模型；
   在正常环境可用 `--multi-process` 恢复标准的多进程隔离。
2. **不支持运行浏览器扩展**：当前内核（CEF 150）已**移除扩展运行 API**
   （头文件里既没有 `LoadExtension`，也没有 `CefExtensionHandler`）。
   「扩展程序」页只做导入 / 解包 / 清单校验 / 登记 / 启用禁用 / 删除，
   扩展脚本与后台任务不会被执行 —— 界面与 `extensions.runtime` 接口都如实说明。
3. **未实现系统打印对话框**：提供「打印为 PDF」（右键菜单），
   `window.print()` 与系统打印机流程需要完整的 `CefPrintHandler`，本版本未接入。
4. **安装包未做代码签名**，Windows SmartScreen 会提示"未知发布者"。
5. 三档安全浏览中依赖云端威胁库的能力需要自备服务商 API Key，界面会明确标注。
6. Microsoft / Google 账户云同步需要自备 OAuth client id；
   本地文件夹同步可直接使用。
7. **密码管理器、阅读模式、页面翻译尚未实现**（Chrome 常见能力中缺的几项）。
8. `%LOCALAPPDATA%\TiBrowser` 在本机用于存放浏览数据
   （不使用 `%APPDATA%`：该目录被 OneDrive 同步会导致 Chromium 缓存占用冲突）；
   可用 `--user-data-dir=<路径>` 指定其它目录。
